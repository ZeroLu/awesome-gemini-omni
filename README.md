> A curated collection of Gemini Omni prompts, bookmarked X demos, and downloadable reference videos.

This repository focuses on Gemini Omni examples surfaced from real X bookmarks. It keeps the exact prompt fragments we could recover from the posts, saves the original demo videos locally, and separates prompt-bearing posts from comparison or announcement posts.

## 1. Prompt Cases

### 1.1. London Eye Refocus Demo
*A concise Gemini Omni Flash prompt that tests world knowledge, handheld motion, zoom behavior, and refocusing.*

**Prompt:**
```text
a recording from a capsule on the london eye, a jerky zoom into something in the distance and then refocusing (with a bit of back and forth) (no timestamp or dialog)
```

## 3. Prompt Extraction Notes

- `fofrAI` contains a clean, reusable prompt and is preserved verbatim.
- `TomLikesRobots` clearly labels the post with `Prompt:` but the exported X metadata truncates the sentence after `A professor writes out a mathematical proof for`. This repository intentionally keeps the exact recoverable fragment instead of guessing.
- `JSFILMZ` and `Google DeepMind` are useful bookmarked videos, but they are descriptive showcase posts rather than prompt posts.
