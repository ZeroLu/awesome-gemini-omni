## 1. Prompt 案例

### 1.1. 伦敦眼拉焦 / 回焦测试
*一个很短但很有代表性的 Gemini Omni Flash 提示词，主要测试世界知识、手持感、镜头拉近和重新对焦。*

**提示词：**
```text
a recording from a capsule on the london eye, a jerky zoom into something in the distance and then refocusing (with a bit of back and forth) (no timestamp or dialog)
```

## 3. Prompt 提取说明

- `fofrAI` 这条带的是完整、可直接复用的 prompt。
- `TomLikesRobots` 明确写了 `Prompt:`，但从可导出的 X 元数据看，句子只保留下 `A professor writes out a mathematical proof for`，后半句已经截断，所以仓库里只保留可核实部分。
- `JSFILMZ` 和 `Google DeepMind` 这两条更适合当对比或展示素材，不属于完整 prompt 帖。
